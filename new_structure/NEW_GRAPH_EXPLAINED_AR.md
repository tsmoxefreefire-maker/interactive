# جراف النبات بالستركشر الجديد · شرح بسيط

**الملف:** `plants_book_graph.json`
**المرجع:** كلام عمر عصام بملفات المشروع (الهرم الجديد + الجداول اللي اقترحها).

---

## ١. الهرم الجديد (من كلام عصام)

```
الكتاب: العلوم · الصف الرابع
 └── الوحدة: النباتات                      ← نفس وحدات الكتاب
      ├── الـ Topic: تركيب النبات وحاجاته   ← تجميع دروس نفس الفكرة (طبقة مصنوعة)
      │    ├── الدرس: أجزاء النبات   (23 دقيقة)
      │    │    └── الجذر · الساق · الورقة · الزهرة · الثمرة · البذرة
      │    └── الدرس: حاجات النبات   (12 دقيقة)
      │         └── الماء · ضوء الشمس · الهواء · التربة
      └── الـ Topic: دورة حياة النبات
           └── الدرس: من البذرة إلى النبتة  (15 دقيقة)
                └── الإنبات · التلقيح · انتشار البذور
```

**ليش Topicين؟** عشان نوري فكرة عصام: الـ Topic **بيجمع دروس نفس الفكرة**. «أجزاء النبات» و«حاجات النبات» فكرتهم وحدة (التركيب)، فانجمعوا تحت Topic واحد.

---

## ٢. الجداول (من اقتراح عصام)

الملف فيه **٥ أقسام** من جداول عصام (+ قسم سادس **تجريبي** للأرقام، تحت):

| القسم | الجدول عند عصام | فيه |
|---|---|---|
| `book` | `Book(id, title, subject)` | الكتاب |
| `nodes` | `Node(id, book_id, title, learning_objective)` | **كل** العقد: وحدات، Topics، دروس، مفاهيم |
| `relationships` | `Relationship(id, source_node_id, target_node_id, type, weight)` | العلاقات |
| `node_metadata` | `NodeMetadata(node_id, difficulty, estimated_minutes, importance)` | صعوبة، دقائق، أهمية |
| `node_content` | `NodeContent(node_id, content_type, content_url, content_text)` | محتوى كل مفهوم |

**ما حطيت** `StudentNodeState` لأنه **حالة الطالب**، مش جزء من الكتاب.

## ٣. كل قسم بالتفصيل

### `book`
```json
{"id": "sci_g4", "title": "العلوم · الصف الرابع", "subject": "Science"}
```
عصام: «كل كتاب لمادة وحدة» ✅

### `nodes` (١٩ عقدة)
```json
{"id": "root", "book_id": "sci_g4", "title": "الجذر", "learning_objective": "", "level": "entity"}
```
| الحقل | ليش |
|---|---|
| `book_id` | كل عقدة بتعرف كتابها (عصام) |
| `title` | الاسم (عصام: «هي ال entity نفسها، بتساوي ال text») |
| `learning_objective` | **هدف التعلّم**. حطيته للوحدة والـ Topics والدروس. المفاهيم فاضية لأنه هدفها جزء من هدف الدرس |
| `level` | 💡 **إضافة مني**: `unit` / `topic` / `lesson` / `entity`. جدول عصام **ما فيه** حقل بيحكي العقدة بأي مستوى، فبدونه ما بنعرف مين درس ومين مفهوم |

### `relationships` (٢٩ علاقة)
```json
{"id": "r1", "source_node_id": "root", "target_node_id": "stem", "type": "prerequisiteOf", "weight": 0.9}
```
**نوعين:**

**أ. `subsetOf` = الهرم (١٨ علاقة)** · الوزن دايماً `1.0`
مفهوم ← درسه، درس ← الـ Topic، Topic ← الوحدة.
**ليش؟** عصام نفسه شرح إنه `subsetOf` بيعمل الهرم: «linear equations, matrices –(subset of)→ linear algebra».

**ب. `prerequisiteOf` = متطلب سابق (١١ علاقة)** · **بين المفاهيم بس**
**ليش بين المفاهيم بس؟** **قرار المهندس:** «العلاقات بين المفاهيم».

| العلاقة | الوزن | ليش |
|---|---|---|
| التربة ← الجذر | 0.6 | التربة بتعطي الجذر المي |
| الماء ← الجذر | 0.7 | الجذر شغلته يمتص المي |
| الجذر ← الساق | 0.9 | الساق بينقل اللي الجذر امتصه |
| الساق ← الورقة | 0.9 | المي بتوصل للورقة من الساق |
| ضوء الشمس ← الورقة | 0.8 | الورقة بتصنع الغذاء من الشمس |
| الهواء ← الورقة | 0.5 | الورقة بتاخد غاز من الهوا |
| الزهرة ← التلقيح | 0.9 | التلقيح بيصير بالزهرة |
| التلقيح ← الثمرة | 0.9 | الثمرة بتطلع بعد التلقيح |
| الثمرة ← البذرة | 0.8 | البذرة جوا الثمرة |
| البذرة ← الإنبات | 0.9 | الإنبات = البذرة بتنبت |
| البذرة ← انتشار البذور | 0.7 | لازم تعرف البذرة قبل ما تعرف كيف بتنتشر |

**`weight` (الوزن)** 💡: حقل جديد من عصام **بدون تعريف**. أنا استعملته = **قديش المتطلب ضروري** (1 = ضروري جداً). **لازم يتأكد مع عصام.**

**لاحظ:** في علاقات **بين دروس مختلفة** (التربة من «حاجات النبات» ← الجذر من «أجزاء النبات»). وهاد **طبيعي**، لأنه العلاقات بين المفاهيم، مش بين الدروس.

### `node_metadata`
```json
{"node_id": "leaf", "difficulty": "medium", "estimated_minutes": 5, "importance": 0.9}
```
| الحقل | ليش |
|---|---|
| `difficulty` | سهل / متوسط / صعب. **محرك الأدلة بيحتاجها** (Pace وChal) |
| `estimated_minutes` | دقائق المفهوم |
| `importance` | حقل جديد من عصام: قديش المفهوم مهم (0–1) 💡 |

**والدروس كمان إلها دقائق** = **مجموع دقائق مفاهيمها**:
| الدرس | الحساب | الدقائق |
|---|---|---|
| أجزاء النبات | 4+4+5+4+3+3 | **23** |
| حاجات النبات | 3+3+3+3 | **12** |
| من البذرة إلى النبتة | 5+6+4 | **15** |

**المصدر:** **قرار المهندس**: «مدة الدرس = مجموع مدد مفاهيمه». 📄

### `node_content`
```json
{"node_id": "root", "content_type": "text", "content_url": null, "content_text": "الجزء تحت الأرض؛ يثبّت النبتة ويمتص الماء والأملاح من التربة."}
```
**هاد بدل `description` بالجراف القديم.** ومنه **الأسئلة التفاعلية بتاخد المعاني** (لعبة «وصّل»).
`content_url` فاضي هلأ، بس ممكن يصير **رابط رسمة** للمفهوم (ومنه أسئلة «سمّي على الرسمة»).

### `node_quantities` (اختياري، للمواد الرقمية بس)
إذا الكتاب **رياضيات/فيزياء/كيمياء** وفيه **أرقام حقيقية** لمفهوم، بتنحط هون، والمصنع بيعمل منها لعبة **«اضبط»**. **كتاب النبات ما فيه** (درس حفظ وفهم).

## ٤. شو تغيّر عن الجراف القديم؟

| | **القديم** | **الجديد** |
|---|---|---|
| الشكل | قائمتين: مفاهيم + علاقات | **٥ جداول** |
| الهرم | كله بنفس المستوى | **وحدة ← Topic ← درس ← مفهوم** |
| الكتاب | مش موجود | **جدول لحاله** |
| الوصف | `metadata.description` | **`node_content.content_text`** |
| الوقت والصعوبة | مش موجودين | **`node_metadata`** |
| العلاقة | بدون وزن | **فيها `weight`** |

---

## ٥. من المشروع ولا اجتهاد؟

| | |
|---|---|
| الهرم (كتاب ← وحدة ← Topic ← درس ← مفهوم) | 📄 عصام |
| الجداول والحقول | 📄 عصام |
| الإتقان والعلاقات على **المفاهيم** | 📄 المهندس |
| دقائق الدرس = مجموع مفاهيمه | 📄 المهندس |
| `subsetOf` للهرم | 📄 شرح عصام |
| حقل `level` | 💡 مني (جدول عصام ناقصه) |
| معنى `weight` و`importance` وأرقامهم | 💡 مني |
| محتوى الدرس نفسه | 💡 تجريبي |
| جدول `node_quantities` (الأرقام) | 💡 اقتراح، للمواد الرقمية بس |

## ٦. أسئلة لعصام
١. **كيف بنعرف العقدة بأي مستوى؟** (حقل `level` ولا طريقة ثانية؟)
٢. **شو معنى `weight`** بالعلاقة؟
٣. **شو معنى `importance`** وكيف بينحسب؟
٤. **ممكن نشوف ملف الجراف الجديد الحقيقي** عشان نطابقه بالحرف؟
