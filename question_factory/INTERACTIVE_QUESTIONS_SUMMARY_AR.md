## ١. شو التاسك؟

عمر عصام طلب **٣ أشياء تفاعلية لكل درس**:

| # | الشي | مين |
|---|---|---|
| ١ | قصة تفاعلية | مش حارث |
| ٢ | شرح تفاعلي | مش حارث |
| ٣ | **أسئلة تفاعلية (شبه ألعاب)** | **حارث** ✅ |

**وكيف تنعمل (كلامه):**
> «خذ درس واحد من الجراف ← ولّد إله الأسئلة ← احفظ البيانات مع الدرس. ولكل الدروس الموجودة.»

**وأهم شرط (كاتبه بالكابيتال):** **لازم تكون تفاعلية** = الطالب **يعمل** إشي، مش يتفرج.

**ومثاله:** درس المغناطيس: الطالب **بيحرّك المغناطيسات** ليوصل للجواب.

**وسألناه:** الأسئلة للدرس كامل، ولا لكل مفهوم؟ **جوابه: لكل مفهوم أسئلته.** ✅

---

## ٢. الستركشر: الدرس شو هو؟

```
الكتاب ← الوحدة ← الـ Topic ← الدرس ← المفاهيم (Entities)
```

- **الدرس بيتقسم لمفاهيم.** الدرس **مش** هو المفهوم.
- **الجدولة على الدرس**، و**الإتقان على المفهوم**، و**العلاقات بين المفاهيم** (قرارات المهندس).
- **دقائق الدرس = مجموع دقائق مفاهيمه.**

**مثال:**
```
📗 درس: أجزاء النبات (23 دقيقة)
 ├── الجذر · الساق · الورقة · الزهرة · الثمرة · البذرة
 └── ✨ الأسئلة التفاعلية ← لكل مفهوم أسئلته، وبتنحفظ مع الدرس
```

## ٣. شو عملنا؟ (بالترتيب)

### أ. استلهمنا من ٣ مواقع بعتهم المهندس

| الموقع | شو أخذنا |
|---|---|
| **Brilliant** | **قوالب ألعاب** ثابتة + **الموديل بيعبّي البيانات** + الغلط **بيبين باللعبة** + **مراجعة بشرية** قبل النشر |
| **Physiworld** | **الحل خطوة خطوة** بعد الجواب + **علامة** على المحاولة + **الغلط بيرجع** بالمراجعة + **صعوبة** لكل سؤال |
| **Explorables** | هاد **للشرح** (مش إلنا)، بس أخذنا منه شكل «الملعب» لسؤال واحد |

### ب. العيّنة 🌱 (درس واحد، جودة عالية)

**درس «أجزاء النبات»**، بـ **٦ أسئلة غنية بالرسومات**:

| السؤال | الطالب بيعمل | النبتة بتتفاعل |
|---|---|---|
| سمّي الأجزاء | بيسحب الاسم لمكانه | الجزء بيضوّي |
| وصّل بشغلته | بيوصل الجزء بوظيفته | الورق بيذبل إذا غلط |
| شغّل النبتة | بيرتب طريق المي والتكاثر | **المي بتطلع**، والبذرة **بتنبت** |
| شو بيصير لو…؟ | بيتوقع قبل ما يشوف | بنشيل الجزء فعلاً |
| النبتة الذبلانة | بيفحص بالعدسة ويصلّح | **النبتة بترجع تعيش** |
| خلّي النبتة تطلّع بذور | بيضبط الشمس والمي والحشرات | زهرة ← ثمرة ← بذرة ← نبتة جديدة |

**هدفها:** نوري المهندس **الجودة** اللي ممكن نوصلها. (رابط «أجزاء النبات · أسئلة تفاعلية»)

### ج. المصنع 🏭 (الطلب الحقيقي)

**كود بيمر على كل الدروس، ولكل مفهوم جوا الدرس:**
```
اقرأ الدرس من الجراف ← لكل مفهوم: ولّد أسئلته ← افحصها ← افحص التغطية ← احفظ مع الدرس ← بانتظار المعلم
```

**١٣ نوع تحدي، كل تحدي عن مفهوم واحد، وكلهم بيشتغلوا بالإصبع على التلفون:**

| | التحديات |
|---|---|
| **المعنى** | 🤥 مين الصادق؟ (الكذابين أنوفهم بتطول) · 🌷 وصّل (البرعم بيزهر) · 🃏 الذاكرة · 🔤 ركّب الاسم · 👉👈 صح ولا غلط (اسحب البطاقة) |
| **العلاقات** | 🌉 ابنِ الجسر (الحجر الغلط بيوقع والكرة بتغرق) · 🚂 صلّح القطار · 🚪 افتح الباب (الباب بيضحك، ووراه المفهوم) · 🗺️ ضوّي الطرق · 🛗 المصعد (القطة بالطابق الغلط) · 👽 الدخيل (صحن طائر بيسحبه) · 🕵️ مين أنا؟ |
| **الأرقام** | 🎚️ اضبط (زي المغناطيس) |

**وفوقهم:** **وضع طالب** طفولي (خريطة دروس بأقفال، طريق محطات، نبتة بتكبر، ملصقات) و**وضع مهندس**، شخصية **«بذور» 🌱** بتتفاعل مع كل حركة، **كل الصور حيّة** وبتتحرك، **أصوات تفاعلية** 🔊، وأي إشي بتفلته بالهوا **بيطير ويتشقلب**، **نجوم** بدل الأرقام، و**جو حسب الدرس** (جنينة لدروس النبات). **المصنع بيختار لكل مفهوم ٤ تحديات منوّعة**، وولا نوع بيتكرر بأكثر من نص الدرس.

**التفاصيل كاملة:** `CHANGES_AR.md`.

### د. على الستركشر الجديد 📘

عملنا **كتاب تجريبي** بالهرم الجديد (جداول عصام):
```
العلوم · الصف الرابع
 └── النباتات
      ├── تركيب النبات وحاجاته
      │    ├── أجزاء النبات (23 د)     ← 6 مفاهيم
      │    └── حاجات النبات (12 د)     ← 4 مفاهيم
      └── دورة حياة النبات
           └── من البذرة للنبتة (15 د) ← 3 مفاهيم
```
والمصنع **صار يقرأه**، والأسئلة طلعت **بالعربي**.

### هـ. فحص التغطية 🎯

**الإتقان على المفهوم**، فلازم **كل مفهوم** إله أسئلة كفاية:
- كل مفهوم لازم **٢ أسئلة على الأقل** (💡 رقم بالإعدادات).
- إذا مفهوم أقل ← **تحذير**.
- **النتيجة:** كل الـ ١٣ مفهوم **جاهزين** (٣–٤ أسئلة لكل واحد).

## ٤. الحماية: ليش الأسئلة موثوقة؟

| الحماية | يعني |
|---|---|
| **قوالب ثابتة** | الموديل ما بيخترع لعبة، بيعبّي **بيانات بس** |
| **الفحص** | بيرفض: مفهوم مخترع، ترتيب مش ماشي على الجراف، متطلب مزيّف، جواب صح مش بالخيارات… |
| **ما بيظلم الطالب** | المتطلب **غير المباشر** (الماء قبل الورقة) ما بينحسب «غلط» |
| **التغطية** | ولا مفهوم بيضل بلا سؤال |
| **الموديل إذا خرب** | المصنع **ما بيوقف**، بيكمّل بدونه |
| **بانتظار المعلم** | ما بيوصل للطالب قبل الموافقة |
