# مصنع الأسئلة التفاعلية · شرح بسيط

## الفكرة بجملة
**كود بيمرّ على كل درس بالجراف، ولكل مفهوم جوا الدرس بيطلّع أسئلته التفاعلية، بيفحصها، وبيحفظها مع الدرس.**
- عمر: «خذ درس من الجراف ← ولّد ← احفظ مع الدرس».
- وجوابه على سؤالنا: **«لكل مفهوم أسئلته»**.

## الخطوات
```
١. اقرأ الجراف (جديد أو قديم)        graph_reader.py
٢. لاقي الدروس                      Graph.lessons()
٣. لكل مفهوم: ولّد أسئلته           offline_generator.py  (أو llm_generator.py لما الموديل يتوصل)
٤. افحص كل سؤال                     validator.py
٥. فحص التغطية: كل مفهوم ≥ 2 أسئلة   main.py
٦. احفظ                             storage.py
٧. بانتظار مراجعة المعلم
```

## شكل الملف المحفوظ
```
درس: أجزاء النبات
 ├── الجذر  ← 4 أسئلة: المعنى، رتّب، شو قبله؟، شو بعده؟
 ├── الساق  ← 4 أسئلة
 ├── الورقة ← 3 أسئلة
 └── ...
```

## القوالب الـ ١٣ (كل تحدي عن مفهوم واحد)

| | القالب | الطالب بيعمل |
|---|---|---|
| **معنى** | 🤥 `meaning` مين الصادق؟ · 🌷 `match` وصّل · 🃏 `memory` الذاكرة · 🔤 `spell` ركّب الاسم · 👉👈 `true_false` صح ولا غلط | يفهم **شو المفهوم** |
| **علاقات** | 🌉 `sequence` الجسر · 🚂 `fix_chain` صلّح القطار · 🚪 `prereq` افتح الباب · 🗺️ `unlocks` ضوّي الطرق · 🛗 `sort` المصعد · 👽 `odd_one_out` الدخيل · 🕵️ `who_am_i` مين أنا؟ | يفهم **وين المفهوم** من غيره |
| **أرقام** | 🎚️ `adjust` اضبط | يضبط كمية (بدها أرقام بالجراف) |

**كل تفاعل بيشتغل بالماوس وبالإصبع**، و**الكبس بديل** للسحب. والتفاصيل كاملة بـ `CHANGES_AR.md`.

### كيف المصنع بيختار لكل مفهوم؟ (`pick()`)
- **تحدي معنى واحد** نوعه **بيدور** من مفهوم لمفهوم.
- **«اضبط»** إذا الجراف فيه أرقام للمفهوم.
- **الباقي علاقات** بترتيب بيدور.
- **ولا نوع بأكثر من نص مفاهيم الدرس** (عشان ما يتكرر).
- **٢ لـ ٤** تحديات لكل مفهوم.

### الخيارات الغلط (`tiered()`)
من **نفس الدرس** أول، بعدين **نفس الـ Topic**، بعدين **الوحدة**، بعدين الكتاب. عشان الخيارات الغلط **تخلّي الطالب يفكّر**.

### تلميحات وبطاقات قصيرة (`fragments()` و`tiny()`)
- `fragments()` بتقسم المعنى لقطع **عن الإشي نفسه** («الجزء تحت الأرض» / «يثبّت النبتة» / «يمتص الماء…»). منها تلميحات **مين أنا؟**، وآخر تلميح أوضح واحد.
- `tiny()` بتعطي **معنى قصير** (٦ كلمات بالكثير) لبطاقات **الذاكرة** وتعريف شخصيات **الدخيل**.

### رحلة الخريطة (`make_unlocks()`)
`route` = المفهوم وبعده لحد ٣ محطات · `junctions` = بكل مفترق **طريق صح واحد** وطرق غلط **مش مربوطة** · `hints` = تلميحات البومة (سؤال ← تذكير ← أول حرفين).

### صور المفاهيم (`icon_for()`)
لكل مفهوم صورة من **قائمة مقفولة** (🫚 الجذر، 🌿 الساق…)، وإذا ما عرف 🔹.

### الجو (`choose_theme()`)
«جنينة» 🌿 إذا الدرس عن النبات، وإلا «عام». **نفس الألعاب، شكل مختلف.**

## كل ملف وكل دالة

### `config.py` — الأرقام
`MIN_QUESTIONS_PER_CONCEPT = 2` و`MAX_QUESTIONS_PER_CONCEPT = 4`، عدد الخيارات الغلط، أطول سلسلة، **القوالب السبعة المسموحة**، والصعوبة لكل قالب.

### `graph_reader.py` — قارئ الجراف
| الدالة | شو بتعمل |
|---|---|
| `Graph.load()` | بتقرأ الملف، وبتعرف لحالها **جديد** (جداول) ولا **قديم** (قائمتين). |
| `_read_new()` | العقد، الميتاداتا (صعوبة، دقائق، أهمية)، المحتوى (المعنى)، والعلاقات. |
| `Graph.lessons()` | الدروس (`level = lesson`) مع مفاهيمها والـ Topic والوحدة، و**دقائق الدرس = مجموع مفاهيمه**. |
| `is_prereq(a, b)` | `a` قبل `b` **مباشرة**؟ |
| `ancestors(x)` | **كل** اللي قبل `x` (مباشر وغير مباشر). |
| (أرقام) | بيقرأ `node_quantities` **التجريبي** لأسئلة الشريط. |
| `descendants(x)` | **كل** اللي بعد `x`. |

### `templates.py` — شكل كل قالب
`SCHEMAS` = الحقول المسموحة لكل قالب (أي إشي زيادة بينرفض). وكل سؤال فيه `target` (المفهوم تبعه) و`concepts` (اللي بيفحصهم).

### `offline_generator.py` — المولّد بدون موديل
| الدالة | شو بتعمل |
|---|---|
| `generate()` | **لكل مفهوم** بالدرس بتجرّب القوالب السبعة، وبعدين `pick()` بيختار منها **خليط منوّع**، وبترجع **سبب** كل قالب ما زبط. |
| `make_meaning()` | المعنى الصح من الجراف + ٣ معاني **لمفاهيم ثانية** كفخ. |
| `chain_through()` + `make_sequence()` | **سلسلة حوالين المفهوم** (اللي قبله واللي بعده)، بتفضّل ٣ حجارة فأكثر، و**ما بتتكرر نفس السلسلة** لمفهومين بنفس الدرس (عشان الطالب ما يملّ). |
| `make_prereq()` | الصح = اللي قبله مباشرة. والغلط = مفاهيم **مش قبله أبداً** (ولا غير مباشر). |
| `make_unlocks()` | الصح = اللي بعده مباشرة. والغلط = مفاهيم **مش مرتبطة فيه أبداً**. |
| `make_match()` | المفهوم + جارين إله، كل واحد مع معناه. |
| `make_sort()` | الأقرب **قبله** والأقرب **بعده** (لحد ٣ بكل سلة). |
| `make_adjust()` | شريط من **أرقام الجراف** (`node_quantities`): الصح بين حدين، وبيبلش برا الصح. |
| `pick()` | **بيختار خليط منوّع** لكل مفهوم (انظر فوق). |

### `llm_generator.py` — المولّد بالموديل
التعليمات بتطلب: **لكل مفهوم أسئلته** (٢ على الأقل)، بالقوالب المسموحة بس، والترتيب ماشي على الجراف، وبالعربي، و«رجّع JSON بس». وأي رد خربان بينرفض.

### `validator.py` — الفحص
بيرفض: قالب غريب، حقل زيادة أو ناقص، **سلة غلط** بـ«قبله ولا بعده»، **«وصّل» بدون المفهوم نفسه**، **شريط بيبلش على الجواب** أو بدون أرقام بالجراف، **مفهوم من درس ثاني**، `concepts` ما بتبلش بالمفهوم، مفهوم مخترع، ترتيب مش ماشي على الجراف، متطلب مزيّف، **«بعده» مزيّف**، مفهوم مرتبط معلّم غلط، معنى صح مش بالخيارات، سؤال بلا حل.

### `main.py` — الباب الوحيد
| الدالة | شو بتعمل |
|---|---|
| `run_factory()` | لكل درس ← لكل مفهوم ← ولّد ← افحص ← **تغطية** ← احفظ. |
| `build_lesson()` | درس واحد. إذا الموديل موصول **بيجرّبه أول**، والغلط **بينرفض**، والناقص **بيتكمّل** بدون موديل. وإذا خرب **ما بيوقف**. وبيحسب **التغطية**: مفهوم أقل من ٢ أسئلة ← تحذير. |

### `storage.py` — الحفظ
`save_lesson()`: ملف الدرس (مقسم على المفاهيم، مع الكتاب والوحدة والـ Topic والدقائق). `save_index()`: فهرس فيه كل درس وكل مفهوم وكم سؤال.

### `player/` — صفحة العرض
**وضعين:** 👧 **الطالب** (عالم ألعاب: ترحيب، خريطة دروس بترتيب التعلّم مع أقفال، طريق محطات، نبتة بتكبر، ملصقات) و⚙️ **المهندس** (الملفات، الأدلة، التغطية). `build_player.py` بيحسب **مين لازم قبل مين** من علاقات الجراف (بدون أقفال دائرية).

### (قديم) صفحة العرض بلمسات لعب
اختار درس ← **رحلة الدرس**: كل مفهوم **محطة** وفيها **نجوم** ⭐ ← جاوب تحدياته. وكل نوع سؤال إله **لعبة خفيفة**:

| السؤال | اللعبة | لما يغلط | لما يصيب |
|---|---|---|---|
| المعنى | 🫧 **اصطاد الفقاعة** الصح | الفقاعة بتختفي | بتنفجر وبيطلع احتفال |
| رتّب | 🌉 **ابنِ الجسر** ودحرج الكرة | **الكرة بتوقع بالمي** عند الحجر الغلط | الكرة بتعبر |
| شو قبله؟ | 🔐 **افتح الباب** بالمفاتيح | المفتاح ما بيفتح | كل مفتاح بيفتح قفل، والباب بينفتح |
| شو بعده؟ | 🗺️ **ضوّي الطرق** | ما في طريق | الطريق بيضوّي والمحطة بتبين |

**ونفس الأسئلة ونفس الفحص**، بس الطالب **بيشوف نتيجة حركته** (فكرة Brilliant). ومعها: علامة، حل خطوة خطوة، **🎯 بيفحص**، ودليل لمحرك الأدلة **للمفهوم نفسه**.

## الفحوصات (59)
- **الجراف الجديد:** بيقرأه صح (الدروس، الهرم، الدقائق، المعاني، العلاقات غير المباشرة).
- **لكل مفهوم أسئلته:** كل مفهوم بين ٢ و٤، كل سؤال تابع لمفهومه، كل مفهوم إله سؤال معنى (فقاعات أو خطوط)، **كل درس فيه ٤ أنواع تفاعل على الأقل**، **الشريط بس للمفاهيم اللي إلها أرقام**، والنقص بيطلع تحذير.
- **الأسئلة:** كلها صالحة، بس مفاهيم فيها، السلسلة فيها المفهوم وماشية على الجراف، **ولا سلسلة بتتكرر بنفس الدرس**، ولا مفهوم مرتبط معلّم غلط، والمعنى إله جواب واحد صح.
- **الشكل القديم** لسا شغال.
- **الفحص بيرفض** ١١ نوع غلط.
- **الموديل:** رد صح بينستعمل، خربان ← رجوع، سؤال غلط ← بينرفض.
- **المصنع كامل** بيحفظ كل الدروس مقسمة على المفاهيم.

**وبالمتصفح:** كل الـ ٥٢ تحدي انحلّوا، **وردود الفعل** كلها مجرّبة (الأنف، الورقة، الحجر، القطة، الباب…)، و**السحب بالماوس وبالإصبع على تلفون**.

## الموديل (LLM) 🤖 · `llm_gateway.py` و`llm_polish.py`

**الفكرة:** الموديل **محرّر صياغة**، مش مؤلف. المصنع بيبني الأسئلة **صحيحة** أول، وبعدين الموديل **بيعيد كتابة الكلام** للأطفال.

| الملف | شو بيعمل |
|---|---|
| `llm_gateway.py` | **البوابة:** `generate(system, user)` بتحكي مع **Claude API** (`POST https://api.anthropic.com/v1/messages`) بمكتبة بايثون العادية (بلا تنصيب). المفتاح من `ANTHROPIC_API_KEY`، والموديل من `ANTHROPIC_MODEL` (افتراضي `claude-sonnet-5-5`). |
| `llm_polish.py` | **المحرّر:** بيجمع **كل كلام** الطالب بيقرأه (السؤال، التلميحات، الجمل، الأوصاف، «ليش»…)، بيبعثه للموديل مع **قواعد**، وبيرجّعه مكانه. |

**القواعد اللي بتنبعت للموديل:** نفس المعنى ونفس الحقائق · الصح بيضل صح والغلط بيضل غلط · ما ينقل معنى من مفهوم لمفهوم · الأسماء بين «…» ما تتغير · عربي بسيط · رجّع JSON بس.

**الحماية (الكود بيفحص كل جملة):**
- لازم ترجع **نفس المفاتيح**، ومش **فاضية**، ومش **أطول بكثير**.
- **كل اسم «…»** لازم يضل، و**ولا اسم جديد** ينضاف.
- **الجمل المتشابهة بتضل متشابهة** (عشان الجواب يضل من الخيارات).
- **كل سؤال بيرجع للفاحص** بعد التعديل؛ إذا فشل **برجع لنسخته الأصلية**.
- إذا الموديل **خرب أو ما رد**، **كله بيضل زي ما هو** مع تحذير.
- **الأجوبة ما بتتغير أبداً** (في فحص لهالشي).

**التشغيل:** `python main.py plants_book_graph.json output_llm --llm`


## الرسومات لأي مادة 🎨 · `ICON_WORDS` + `ART_ICONS` + `llm_art.py`

- بالمشغّل: `"art:<id>"` = رسمة الموديل + **نفس الوجه**.
