# الأسئلة التفاعلية · ملف للمهندس

**إعداد:** حارث الحرازنة · **المهمة:** الجزء ٣ من طلب م. عمر عصام (Interactive Questions)

---

## ١. الطلب (كلام المهندس بالحرف)

> «interactive questions (game-like questions) · **For EACH lesson**»
> «access a lesson at a time **from the graph** (the graph is probably input) · **generate** on that lesson · **save** given data for the lesson»
> «questions that the student can interact with to **solve a game-like problem** related to the lesson. e.g. magnetic field: the student positions magnets…»
> «مثال آخر: ممكن يكون **سؤال وصّل بس بجرافيكس شبه الجيمز**»
> «important point: it **MUST be INTERACTIVE**»
> وجواب لاحق: **«لكل مفهوم أسئلته»**.

---

## ٢. الفكرة بجملة

**مصنع** بيقرأ الجراف، **بيمرّ على كل درس، ولكل مفهوم بيولّد تحديات تفاعلية شبه ألعاب**، **بيفحصها**، و**بيحفظها مع الدرس**. وفي **مُشغّل (Interpreter)** بيقرأ المحفوظ وبيعرضه **ألعاب** للطالب.

```
الجراف ← لكل درس ← لكل مفهوم ← توليد ← فحص ← حفظ مع الدرس ← المشغّل (ألعاب)
```

---

## ٣. كيف بيشتغل بالضبط

| الخطوة | الملف | شو بيصير |
|---|---|---|
| **١. قراءة الجراف** | `graph_reader.py` | بيقرأ **الستركشر الجديد** (كتاب ← وحدة ← Topic ← درس ← مفهوم، جداول: `book`, `nodes`, `relationships`, `node_metadata`, `node_content`) وبيعرف القديم كمان. |
| **٢. الدروس والمفاهيم** | `Graph.lessons()` | كل درس مع مفاهيمه **بترتيب التعلّم** (ولا مفهوم قبل اللي بيحتاجه)، و**دقائق الدرس = مجموع مفاهيمه**. |
| **٣. التوليد** | `offline_generator.py` | **لكل مفهوم** ٢–٤ تحديات **منوّعة** من ١٣ قالب، من **محتوى الجراف** (المعنى والعلاقات). |
| **٤. الفحص** | `validator.py` | **كل تحدي بينفحص**: مفاهيم حقيقية، ترتيب ماشي على الجراف، جواب صح واحد، ولا جملة «ترتيب منهج» بدل العلم… |
| **٥. التغطية** | `main.py` | **كل مفهوم لازم إله تحديين على الأقل**، وإلا تحذير. |
| **٦. الحفظ** | `storage.py` | `lessons/<الدرس>/questions.json` (مقسّم على المفاهيم) + `index.json` لكل الكتاب. الحالة: **«بانتظار مراجعة المعلم»**. |
| **٧. الموديل (اختياري)** | `llm_gateway.py` + `llm_polish.py` | **Claude** بيعيد **صياغة الكلام** للأطفال، **بدون ما يغيّر الأجوبة**. أي جملة بتفشل بالفحص **بترجع لأصلها**. |
| **٨. المشغّل** | `player/` | صفحة بتقرأ المحفوظ وبتعرضه **ألعاب** (كبس وسحب، كمبيوتر وتلفون). |

**التشغيل:**
```
python main.py <graph.json> <output>            ← المصنع
python main.py <graph.json> <output> --llm      ← مع الموديل (يحتاج ANTHROPIC_API_KEY)
python player/build_player.py <graph.json> <output>
```

## ٤. شو بيحتوي: ١٤ نوع تحدي (بيختار حسب المادة)

| | التحدي | الطالب بيعمل | من شو بالجراف |
|---|---|---|---|
| **المعنى** | 🤥 مين الصادق؟ | يسحب الاسم للوجه الصادق (الكذابين أنوفهم بتطول) | المعنى |
| | 🌷 وصّل | يرسم ساق من المفهوم لمعناه (البرعم بيزهر، الغلط بيذبل) | المعنى |
| | 🃏 الذاكرة | يقلب ويطابق المفهوم بمعناه | المعنى |
| | 🔤 ركّب الاسم | يسحب الحروف لمكانها | الاسم + المعنى |
| | 🐸 صح ولا غلط | يطعمي الجملة للوحش الصح | المعنى (جمل علمية) |
| **العلاقات** | 🌉 ابنِ الجسر | يركّب القطع بالترتيب، و**سيارة** بتقطع (الضعيف بيحمرّ وبينكسر) | «متطلب سابق» |
| | 🚂 صلّح القطار | يلاقي العربة الغلط ويبدّلها | «متطلب سابق» |
| | 🚪 افتح الباب | مفاتيح = اللي لازم قبله | «متطلب سابق» |
| | 🗺️ رحلة «مين بيحتاج…؟» | بكل مفترق يختار المحطة الجاية (ثعلوب بيخدع، البومة بتلمّح) | «متطلب سابق» |
| | 🛗 المصعد | يحط المفاهيم: تحت = قبله، فوق = بعده، و«ثبّت» | «متطلب سابق» |
| | 🪴 الدخيل | يشدّ اللي مش من المجموعة («كلهم من حاجات النبات إلا واحد») | الهرم (الدرس) |
| | 🕵️ مين أنا؟ | الشخصية المقنّعة بتعطي تلميحات، ويحزر | المعنى |
| | 🔮 شو بيصير لو…؟ | يتوقّع، والمفهوم بيختفي، واللي بيحتاجوه بيتعبوا (دومينو) | «متطلب سابق» |
| **أرقام** | 🎚️ اضبط | يقرأ معلومة الكتاب، يحط توقّعه، و«جرّب» (زي مثال المغناطيس) | أرقام **حقيقية** من الكتاب · **للمواد الرقمية بس** |

**حسب المادة:** مواد **الحفظ والفهم** (زي العلوم) بتاخد ألعاب المعنى والعلاقات، و**«اضبط» بس للرياضيات والفيزياء والكيمياء** إذا الكتاب فيه أرقام.

**كلهم تفاعليين** (ولا سؤال نص عادي)، و**كلهم بيشتغلوا بالإصبع على التلفون**.

## ٨. شو ناقص (مش بإيدي)

|---|---|

## ١٠. ملخّص بثلاث جمل

١. **مطابق للطلب:** لكل درس من الجراف، **لكل مفهوم** تحديات **تفاعلية شبه ألعاب**، بتنحفظ مع الدرس.
٢. **آمن:** كل تحدي **مفحوص**، و**الموديل بيحسّن الكلام بس**، والمعلم بيراجع.
٣. **جاهز:** يشتغل على **الجراف الحقيقي** أول ما يوصل.
